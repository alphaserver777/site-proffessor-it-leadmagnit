# Сайты «Профессор IT»

В одном репозитории находятся три сайта продуктовой воронки:

| Приложение | Публичный адрес | Назначение |
|---|---|---|
| `lead-magnet` | `https://professorit.ru/guide/kak-voiti-v-it/` | бесплатная карта входа в IT |
| `test-drive` | `https://professorit.ru/` | тест-драйв профессии за 1 000 ₽ |
| `mentorship` | `https://professorit.ru/mentorship/` | основной продукт наставничества |

## Структура

```text
apps/
├── lead-magnet/    # бесплатная карта и статьи
├── test-drive/     # трипваер, анкета и оплата
└── mentorship/     # основной продукт
packages/
└── funnel-shared/  # общая оболочка лид-магнита и тест-драйва
infra/              # единая публикация всех трёх сайтов
scripts/            # сборка общего выпуска
```

Каждое приложение собирается независимо. Общая команда создаёт один каталог
`dist/`, структура которого совпадает с публичными адресами:

```bash
npm ci
npm run build
```

Локальный запуск отдельного сайта:

```bash
npm run dev:test-drive
npm run dev:lead-magnet
npm run dev:mentorship
```

## Публикация

Публикуется только чистая зафиксированная версия из `main`:

```bash
cd infra/ansible
./deploy.sh
```

Если внутренний узел доступен только через Proxmox, используйте команду из
`infra/ansible/README.md`.

Прежний отдельный репозиторий наставничества сохраняется до проверки общего
выпуска. После этого его следует перевести в архив, а не удалять.
