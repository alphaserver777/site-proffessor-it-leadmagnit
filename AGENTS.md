# Правила главного сайта Professor IT

Утверждённая базовая версия — `professorit-v1.0.0`.

- `main` — опубликованная версия, `develop` — следующий выпуск.
- Изменения идут через `feature/*`; срочные исправления — через `hotfix/*`.
- Перед слиянием выполнить `npm run build` и проверить основные публичные пути.
- Формы, аналитика и переходы должны использовать канонический API CRM.
- Конфигурация Nginx является частью версии и не должна существовать только на
  сервере.
- Развертывание выполняется только из метки или явно указанной фиксации.
- Не добавляйте секреты и персональные данные в исходники или журналы.
