# Правила сайта наставничества

- Сайт отвечает только за основной продукт по пути `/mentorship/`.
- Изменение тарифов, договоров и гарантий требует проверки утверждённых условий.
- Перед общей публикацией выполнить сборку приложения.
- Не добавлять внешние зависимости от прежних сайтов-источников.
