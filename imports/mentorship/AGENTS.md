# Правила продажника наставничества

- Утверждённая базовая версия — `professorit-v1.0.0`.
- `main` — опубликованная версия, `develop` — следующий выпуск.
- Работа ведётся в `feature/*`; срочные исправления — в `hotfix/*` от `main`.
- Сайт полностью автономен: запрещено возвращать загрузку интерфейса, данных
  или изображений из `site.criminalit.ru` и других сайтов-источников.
- Перед слиянием выполните `npm run build` и проверьте отправку анкеты через
  `/api/lead` в единый API CRM.
- Публикация выполняется только из чистой `main` сценарием
  `infra/ansible/deploy.sh`.
- Не добавляйте секреты и персональные данные в исходники или журналы.
