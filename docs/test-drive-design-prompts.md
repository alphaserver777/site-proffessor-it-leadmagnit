# Промты для глубокого редизайна `index.html`

Три самодостаточных промта для ИИ-ассистента (Claude Code / Cursor / любой кодовый ИИ).
Каждый описывает **глубокий редизайн главной страницы** сайта-портфолио «Proffessor IT»
(DevOps/Linux/сети/безопасность) в своём визуальном стиле. Цель — выбрать направление,
сравнив результаты глазами.

Как использовать: выбери один блок ниже, скопируй его целиком от «Роль» до «Критерий приёмки»
и вставь ИИ в этом репозитории. Сгенерируй, посмотри. Повтори для другого стиля на отдельной
ветке/копии, чтобы сравнить.

---

## ОБЩИЕ ОГРАНИЧЕНИЯ (входят в каждый промт — не удаляй)

```
СТЕК И ОГРАНИЧЕНИЯ (обязательны):
- Чистый статический сайт: один index.html + styles.css + script.js. Без сборщиков,
  без фреймворков, без npm. Деплой — GitHub Pages из ветки main.
- Сохрани ВЕСЬ текстовый контент и смысл всех секций index.html: шапка/навигация, hero с
  терминальной карточкой, about (фото + текст), «Кому полезно» (персоны + майндмеп + карточки
  направлений), «Планы обучения» (карточки с модалками), Format/Roadmap (этапы), Learning path,
  FAQ (details), CTA-секция и popup, meta-блок, footer. Меняем ТОЛЬКО визуал, вёрстку, эффекты —
  не выкидываем разделы и не переписываем тексты по смыслу.
- Сохрани/улучши адаптивность. Брейкпоинты: 960px, 720px, 480px. Мобильное меню (.menu-toggle)
  должно работать. Проверь, что hero, сетки карточек и майндмеп корректно сворачиваются в 1 колонку.
- Доступность: контраст текста к фону не ниже WCAG AA. Интерактивные элементы — с :focus-visible.
- Сохрани существующую JS-логику: reveal-анимации при скролле (initRevealMotion), CTA-popup по
  времени/скроллу (initCtaPopup), модалки планов, мобильное меню. Можно дополнять, но не ломать.
- Шрифты можно заменить — но укажи, какие Google Fonts подключаешь, и подключи их в <head>.
- Используй CSS-переменные в :root для всей палитры, типографики и эффектов — чтобы стиль был
  единым и легко правился.

КРИТЕРИЙ ПРИЁМКИ:
Главная должна ощущаться как премиум-продукт сильной дизайн-студии — «дорого, будто работала
команда профессионалов», а не как бесплатный шаблон. Внимание к деталям: ритм отступов, выравнивание
по сетке, согласованность радиусов/теней, плавность анимаций, отсутствие «дешёвых» резких градиентов.
После редизайна открой результат и убедись, что он не сломан на мобильном и десктопе.
```

## ПРОМТ 1 — CYBER-LUXURY (индиго + неон-cyan + фиолетовый)

```
Роль: Ты senior product-дизайнер и фронтенд-инженер уровня топ-студии (Vercel/Linear/Stripe вайб).
Задача: сделай глубокий редизайн index.html сайта-портфолио DevOps-специалиста «Proffessor IT» в
стиле CYBER-LUXURY — премиальный тёмный «cyber», развивающий текущую индиго-палитру.

ВИЗУАЛЬНЫЙ СТИЛЬ:
- Палитра (через CSS-переменные):
    --bg: #0a0a0f (глубокий сине-чёрный), второй слой фона #0f0f17;
    --accent: #6366f1 (индиго), --accent-2: #22d3ee (неон-cyan), --accent-3: #a855f7 (фиолетовый);
    --text: #ECECF2, --text-muted: #9a9ab0; success #22c55e, danger #ef4444 — как статусные.
- Фон: не плоский. Большие мягкие radial-градиенты (индиго→прозрачный, cyan→прозрачный,
  фиолет→прозрачный) в углах hero и за крупными секциями. Очень тонкий noise/grid-overlay поверх
  фона (низкая прозрачность), чтобы убрать «пластиковость». Без резких полос.
- Glassmorphism: ключевые карточки и шапка — полупрозрачные с backdrop-filter: blur(20–28px),
  тонкой светлой границей сверху (inset 1px rgba(255,255,255,.08)) и градиентной рамкой
  (border-image или псевдоэлемент с conic/linear-градиентом индиго→cyan).
- Glow: многослойный. У акцентных кнопок и активных карточек на hover — мягкое цветное свечение
  (box-shadow в 3 слоя: тонкое кольцо + среднее + размытое 30–40px) + лёгкий подъём translateY(-2px)
  и scale(1.01). Свечение разное по тону для разных секций (индиго/cyan/фиолет).
- Типографика: заголовки — современный гротеск (например, «Space Grotesk» или «Sora»), очень
  плотный letter-spacing (-0.04em) для крупного hero; текст — «Inter»; код/терминал — «JetBrains
  Mono». Крупный выразительный hero-заголовок (clamp до ~64px на десктопе) с градиентным
  text-fill (индиго→cyan) на одном-двух словах.
- Hero: асимметрия. Слева крупный заголовок + lead + 2 CTA (основная — заполненная градиентом
  индиго→фиолет с glow, вторичная — стеклянная ghost). Справа — прокачанная терминальная карточка:
  цветной вывод (зелёный prompt, cyan команды, серый текст), мигающий курсор, эффект «печати»
  первой строки через JS/CSS-анимацию, заголовок окна с триколор-точками и свечением.
- Секции: чередуй — одни на стеклянных панелях с градиентной рамкой, другие «прозрачные» на фоне.
  Карточки направлений (сети/Linux/DevOps/Security) — с иконкой в неоновом «чипе», цветным верхним
  бордером по тону секции, hover-свечением. Майндмеп и roadmap — с тонкими светящимися линиями-
  коннекторами (gradient stroke).
- Микро-интеракции: плавные (cubic-bezier ease-out 200–260ms), reveal при скролле с blur-fade и
  каскадной задержкой (уже есть — усиль). Курсор-glow за мышью на hero (опционально, лёгкий).

Итог: ощущение дорогого SaaS-лендинга про кибербезопасность — холодно, неоново, премиально.
```

## ПРОМТ 2 — MATRIX / TERMINAL-GREEN (агрессивный хакер)

```
Роль: Ты дизайнер с эстетикой настоящего терминала и демосцены + фронтенд-инженер.
Задача: сделай глубокий редизайн index.html сайта-портфолио DevOps-специалиста «Proffessor IT» в
стиле MATRIX / TERMINAL-GREEN — жёсткий, аутентично «хакерский», как будто весь сайт это консоль.

ВИЗУАЛЬНЫЙ СТИЛЬ:
- Палитра (CSS-переменные):
    --bg: #000000 (чистый чёрный), панели #050805/#0a120a;
    --accent: #00ff66 (кислотно-зелёный фосфор), --accent-dim: #00b347, --accent-deep: #007a30;
    --text: #b8ffcf (зеленовато-белый), --text-muted: #4f9e6a;
    статусы: amber #ffb000 (warning), red #ff3b3b (alert).
- Фон-эффекты «CRT»:
    * scanlines — очень тонкие горизонтальные линии поверх всего (repeating-linear-gradient,
      низкая прозрачность), не мешающие чтению;
    * лёгкое виньетирование по краям экрана (radial темнее к углам);
    * опционально — мягкий «фосфорный» bloom/glow вокруг ярко-зелёного текста (text-shadow).
- Типографика: МОНОШИРИННЫЙ шрифт доминирует — «JetBrains Mono» (или «IBM Plex Mono») почти
  везде: заголовки, навигация, кнопки, подписи. Обычный sans («Inter») — только для длинных
  абзацев, чтобы не утомлять. Заголовки в верхнем регистре с letter-spacing.
- «Командная» подача: секции озаглавлены как команды/пути — например `> ~/who-is-it`,
  `$ cat services.md`, `[root@proffessor]#`. Лейблы-«eyebrow» в виде `// comment` или `# tag`.
  Мигающий блочный курсор `█` после ключевых строк.
- Hero: во весь экран как загрузка системы/boot-лог. Слева — большой ASCII/моно-заголовок с
  эффектом печати (typing) через JS, под ним lead и 2 «кнопки-команды» (рамка из символов или
  `[ Записаться ]` стиль). Справа — крупный терминал с реалистичным выводом: zsh-prompt, вывод
  команд построчно с анимацией появления, разные цвета (зелёный prompt, белый ввод, amber вывод).
- Кнопки/карточки: вид как рамки в TUI — границы `1px` зелёные, на hover «инвертируются»
  (фон зелёный, текст чёрный) или загораются ярче с фосфорным glow; угловые «уголки» (corner
  brackets ┌ ┐ └ ┘) как акцент. Радиусы маленькие или нулевые — это терминал, а не SaaS.
- Майндмеп/roadmap: рисуй связи ASCII-/моно-линиями (│ ├ └ ─) либо тонкими зелёными SVG-stroke
  со свечением. FAQ (details) — как раскрывающиеся лог-блоки.
- Микро-интеракции: эффект печати, мигающий курсор, лёгкий «глитч» на hover заголовков
  (короткий RGB-сдвиг/clip), reveal при скролле — как «подгрузка строк лога».

Итог: ощущение, что зашёл в чужой защищённый сервер — мрачно, фосфорно-зелено, технологично,
но при этом аккуратно и читабельно (не каша из символов).
```

## ПРОМТ 3 — MINIMAL NOIR (строгая роскошь, «дорого через сдержанность»)

```
Роль: Ты арт-директор премиальных брендов и фронтенд-инженер. Эстетика: Apple, Teenage
Engineering, дорогие швейцарские портфолио.
Задача: сделай глубокий редизайн index.html сайта-портфолио DevOps-специалиста «Proffessor IT» в
стиле MINIMAL NOIR — почти монохромная сдержанная роскошь. «Дорого» достигается не яркостью, а
безупречной типографикой, сеткой, ритмом и воздухом.

ВИЗУАЛЬНЫЙ СТИЛЬ:
- Палитра (CSS-переменные), очень узкая:
    --bg: #0c0c0c, поверхности #131313/#181818;
    --text: #f5f5f5, --text-muted: #8a8a8a, --line: rgba(255,255,255,.10);
    ровно ОДИН тонкий акцент — холодный индиго #6366f1 (или платиново-серебристый #cfd3dc),
    используется ТОЧЕЧНО: ссылки, один CTA, маркеры. Никакого неона и пёстрых градиентов.
- Пространство: много whitespace, крупные вертикальные отступы между секциями (clamp 96–160px),
  широкие поля. Контент в строгой 12-колоночной сетке, чёткое выравнивание по бейзлайну.
- Линии вместо эффектов: разделители секций — тонкие 1px линии (--line). Карточки — почти без
  теней, только тонкая граница и едва заметная смена фона на hover; подъём минимальный
  (translateY(-2px)) без glow.
- Типографика — главный герой: заголовки крупным элегантным гротеском («Inter Tight», «Geist»
  или «Neue Montreal»-вайб) с плотным трекингом; крупный hero clamp до ~72px, тонкое начертание
  (300–500). Числа/метрики — табличные. Код/терминал — «JetBrains Mono», но скромно и мелко,
  как деталь, а не аттракцион. Чёткая типографическая иерархия (eyebrow → h2 → текст).
- Hero: спокойный, дорогой. Крупный заголовок, короткий выразительный lead, одна основная CTA
  (тонкая, с подчёркнутой анимацией) + текстовая вторичная ссылка со стрелкой. Терминальная
  карточка — минималистичная: монохромная, тонкая рамка, аккуратный моно-вывод без буйства цвета;
  это «деталь инженерности», а не главный акцент.
- Секции: единый сдержанный ритм. Персоны/направления — как строгий каталог (номер 01/02/03,
  заголовок, описание, тонкая линия). Roadmap — вертикальная шкала с тонкой линией и точками.
  FAQ — минималистичные раскрывашки с плавной анимацией высоты, тонкий разделитель между.
- Микро-интеракции: очень сдержанные и медленные (ease 280–360ms), благородный fade/slide при
  скролле, подчёркивания ссылок «прорастают» слева направо, hover меняет состояние едва заметно.

Итог: ощущение дорогого, уверенного в себе портфолио инженера — тихая роскошь, безупречная
типографика, ничего лишнего. Премиальность через сдержанность, а не через эффекты.
```

## Подсказка по сравнению
- Прогоняй каждый промт на **отдельной ветке** (например `design/cyber`, `design/matrix`,
  `design/noir`) или на копии index, чтобы потом честно сравнить три результата рядом.
- Деплой ветки на GitHub Pages не обязателен для оценки — достаточно открыть index.html локально.
- Выбрав победителя, скажи — доведём выбранный стиль до финала и при желании раскатаем на остальные
  страницы (business.html, resume.html) единым `styles.css`.
